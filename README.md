## CLASSY HWR UI DESIGN

### Description of the Content:
In here you will find a simple UI design as PDF document, made with Affinity (design software published under Canva), for a fictional learning app used at Berlin School of Economics and Law. In theory, the app brings together all of HWR's web resources (like S.A.M., Moodle and Webmail) in one place and takes a centralized approach to usability for student's sake.
